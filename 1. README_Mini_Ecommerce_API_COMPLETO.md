## 📌 Visão Geral

API REST desenvolvida com FastAPI para simular um mini e-commerce
completo, aplicando boas práticas de arquitetura, autenticação JWT,
organização modular e separação de responsabilidades.

------------------------------------------------------------------------

## 🏗️ Arquitetura

Cliente (Front-End) ↓ FastAPI (Backend) ↓ JWT (Autenticação) ↓ Banco de
Dados (SQLite / PostgreSQL)

## 🔐 Autenticação

  Método   Endpoint         Proteção   Descrição
  -------- ---------------- ---------- -----------------------------
  POST     /auth/register   ❌         Criar novo usuário
  POST     /auth/login      ❌         Gerar token JWT
  GET      /auth/me         ✅         Retorna usuário autenticado

------------------------------------------------------------------------

## 🛍️ Produtos

  Método   Endpoint         Proteção
  -------- ---------------- ----------
 ## POST     /products/       Admin
 ## GET      /products/       Público
 ## GET      /products/{id}   Público
  PUT      /products/{id}   Admin
  DELETE   /products/{id}   Admin

## 🔒 Segurança

-   Senhas armazenadas com hash bcrypt
-   Autenticação Stateless via JWT
-   Rotas protegidas com Depends(get_current_user)
-   Controle de roles (admin / cliente)
-   Variáveis sensíveis via arquivo .env

## ▶️ Como Rodar o Projeto

``` bash
git clone SEU_REPOSITORIO
cd mini-ecommerce-api

python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Acesse:

http://127.0.0.1:8000/docs
